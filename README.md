# OCR_FROM_TASK

Распознавание печатного и рукописного русского текста в PDF-сканах и изображениях (паспорта, формуляры, этикетки).
Страница режется на горизонтальные полосы, каждая распознаётся vision-language моделью Qwen3-VL локально, без интернета.

API — один эндпоинт:

```
POST /ocr   (multipart/form-data, поле file — PDF или изображение: JPG, PNG, TIFF, BMP, WebP)
→ {
    "pages": {"1": "текст страницы 1", "2": "текст страницы 2", ...},
    "docx": "<Word-документ по всем страницам, base64>"
  }
```

Текст страниц — в разметке Markdown (заголовки `#`, таблицы `| ... |`). Word-документ собирается
из всех страниц: заголовки, таблицы, каждая страница PDF с новой страницы, альбомные — в альбомной ориентации.

Сохранить Word из ответа:

```bash
curl -s -F "file=@document.pdf" http://localhost:8000/ocr | python -c "import sys,json,base64; open('result.docx','wb').write(base64.b64decode(json.load(sys.stdin)['docx']))"
```

## Офлайн-запуск (контейнер без интернета)

1. На машине с интернетом один раз подготовить проект:
   ```bash
   python scripts/prepare_offline.py
   ```
   Скачиваются все Linux-пакеты (`vendor/wheels`), автономный Python 3.12 (`vendor/python.tar.gz`)
   и веса модели (`models/`).
2. Собрать архив без локальных артефактов (`python scripts/make_bundle.py` → `dist/ocr-offline.tar`),
   распаковать в контейнере и запустить:
   ```bash
   tar -xf ocr-offline.tar && sh ocr/start.sh
   ```
   (или `python3.12 ocr/main.py`, если в контейнере есть Python 3.12).

Подробности и требования к серверу — в [DEPLOY.md](DEPLOY.md).

## Установка для разработки (Windows, NVIDIA GPU)

Нужен Python 3.12 (на 3.14 нет сборок torch с CUDA).

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python scripts\download_model.py                                   # Qwen3-VL-8B, ~17 ГБ (по умолчанию)
.venv\Scripts\python scripts\download_model.py --repo Qwen/Qwen3-VL-4B-Instruct  # опционально, ~8 ГБ, быстрее, хуже на рукописи
```

Веса кладутся в `models/<имя модели>`, после этого интернет не нужен.

## Запуск

```powershell
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

```bash
curl -F "file=@document.pdf" http://localhost:8000/ocr
```

Прогон без сервера (результат в `results/<имя>.json` и `results/<имя>.docx`):

```powershell
.venv\Scripts\python scripts\run_local.py "путь\к\файлу.pdf"
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `OCR_MODEL_PATH` | `models/Qwen3-VL-8B-Instruct` | Папка с весами модели |
| `OCR_QUANT` | `4bit` | `4bit` / `8bit` / `none` (bf16, для GPU от 24 ГБ) |
| `OCR_DPI` | `300` | DPI рендера страниц |
| `OCR_TILE_WIDTH` | `1700` | Ширина, до которой масштабируется страница перед нарезкой на полосы |
| `OCR_MAX_PIXELS` | `1200000` | Максимальный размер одной полосы (на GPU 8 ГБ больше не ставить; на H100 можно 4000000 — полос будет меньше) |
| `OCR_MAX_NEW_TOKENS` | `2048` | Лимит токенов ответа на полосу |
| `OCR_REPETITION_PENALTY` | `1.0` | Штраф за повторы (>1 искажает повторяющиеся значения в таблицах) |
| `OCR_LOG_LEVEL` | `INFO` | `DEBUG` — с сырыми ответами модели; логи в консоли и `logs/ocr.log` |

## Как это работает

1. `app/pdf.py` — рендер страницы (PyMuPDF, 300 DPI) и обрезка пустых полей.
2. Определение альбомных страниц (таблицы, отсканированные боком): OpenCV удаляет линии таблиц
   и сравнивает, вдоль какой оси вытянуты строки текста; в неясных случаях сравнивается уверенность
   модели при чтении страницы как есть и с поворотом. Повёрнутые страницы разворачиваются
   на 90° по часовой стрелке (так подшиты альбомные листы во всех образцах).
3. Нарезка страницы на горизонтальные полосы по пустым промежуткам между строками:
   мелкая рукопись читается заметно лучше в высоком разрешении. Пустые полосы пропускаются.
   Если полоса закончилась таблицей, следующая получает в промпте её шапку и число столбцов —
   таблица продолжается теми же столбцами; дубли и склеенные через `<br>` записи разбираются
   (`app/tables.py`), и в Word таблица собирается в одну.
4. `app/ocr.py` — модель загружается один раз при старте, на каждую полосу одна генерация
   с промптом из `app/config.py`. При зацикливании генерация обрывается и повторяется
   с более сильным штрафом за повторы.
5. `app/docx_export.py` — сборка Word из Markdown-разметки (таблицы, разрезанные на полосы, склеиваются).
6. `app/scheduler.py` — очередь страниц для одновременных запросов (по кругу между запросами,
   отмена при отключении клиента, реплики модели `OCR_REPLICAS`).
7. `app/main.py` — FastAPI-эндпоинт `/ocr`; `app/log.py` — логи (консоль + `logs/ocr.log`).

## Ограничения

- Модель может «додумывать» неразборчивую рукопись (особенно фамилии и подписи) — результат
  по рукописным полям нужно проверять.
- Скорость на RTX 3060 Ti (8 ГБ, 4-bit): 10–60 с на страницу при свободной видеопамяти.
  Требования к серверу и режим без GPU — в [DEPLOY.md](DEPLOY.md).
